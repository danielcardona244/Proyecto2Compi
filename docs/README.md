# GoScript Interpreter

## Descripción
Intérprete web para el lenguaje GoScript, inspirado en Go, desarrollado como proyecto universitario.

## Características
- Lenguaje GoScript con tipos primitivos, structs, slices, funciones
- IDE web con editor, consola y reportes
- Análisis léxico y sintáctico con Jison
- Generación de AST, tabla de símbolos y reportes de errores

## Instalación
1. Backend: `cd backend && npm install`
2. Frontend: `cd frontend && npm install`

## Uso
1. Iniciar backend: `npm run dev`
2. Iniciar frontend: `npm start`
